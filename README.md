# fmxai.org

The site of the Formal Methods × AI event series, generated by
[`sites`](https://github.com/for-all-dev/sites), a static site generator written and verified
in Lean 4. No generated page contains JavaScript.

The one script on the site is the Vibecheck promo, a hand-written canvas animation kept as a
static asset (`public/vibecheck/promo.html`) and embedded on `/vibecheck/` in an `iframe`.

```sh
lake build                     # library, executable, tests
.lake/build/bin/fmxai build    # writes dist/
.lake/build/bin/fmxai serve    # http://127.0.0.1:8080/, pages from memory, assets from public/
scripts/check.sh               # everything above plus escape-hatch audit and leanchecker
```

With Nix, `nix develop` provides `elan`, which picks up `lean-toolchain`.

## Layout of the repository

| Path | What it is |
| --- | --- |
| `Fmxai/Route.lean` | The four routes, and the header, footer and other shared markup. |
| `Fmxai/Pages/*.lean` | The pages, as Lean terms in the typed HTML DSL. |
| `Fmxai/Site.lean` | The `Site`: document chrome and the route table with its proofs. |
| `public/` | Static files copied verbatim into `dist/`: CSS, images, favicon, `CNAME`. |
| `Main.lean` | `build` and `serve`. |
| `Test.lean` | Executable checks and the axiom audit. |

## What is verified

Everything the library proves applies to this site: every page's HTML is produced by a
printer with a proven inverse (`Sites.Site.parse_html`), the build writes exactly the listed
files (`Sites.Site.build_pages`), and internal links are values of `Fmxai.Route`, so a link to
a page that does not exist is a type error. (The old 2026 page had a link to
`https://https://fmxai.org/` and an unclosed `<a>`; neither is expressible now.)

Nothing uses `partial`, `noncomputable`, `unsafe`, `implemented_by`, `native_decide`, `sorry`
or new axioms; `scripts/check.sh` greps for them, `Test.lean` pins the axioms the site depends
on, and `leanchecker` re-checks the compiled proofs independently of the elaborator.

## Editing the site

- Prose and markup: `Fmxai/Pages/*.lean`. Elements are functions named after their tags,
  strings are text, `a [.href (.route .y2026)] ["2026"]` is an internal link.
- Styling: `public/styles.css`, kept as plain CSS so that the site looks exactly as it did.

## Deployment

GitHub Pages, from the `dist/` artifact built by `.github/workflows/pages.yml` on pushes to
`main`. `public/CNAME` keeps `fmxai.org` pointed at it. The repository's Pages source must be
set to *GitHub Actions* rather than a branch.

The `sites` dependency is pinned in `lake-manifest.json` to a commit on its `master` branch.
